# 菜鸟驿站管理系统 (Courier Station Management System)

## 📖 项目简介
这是我在大二上学期独立完成的首个 C 语言数据结构实战项目。使用**顺序表（数组）**模拟了菜鸟驿站的包裹管理流程。

## ✨ 核心功能
- [x] 录入新包裹（支持输入单号和收件人姓名）
- [x] 查看所有包裹列表（按录入顺序遍历输出）
- [x] 循环交互菜单系统（支持连续操作直到主动退出）

## 🛠️ 技术栈
- **编程语言**：C Language
- **核心知识点**：
  - 结构体 (Struct) 的自定义与嵌套
  - 顺序表 (Sequential List) 的初始化与插入
  - `while(1)` 循环与 `switch-case` 分支控制流

## 🚀 如何运行
1. 下载 `test.c` 文件。
2. 使用任意 C 语言编译器（如 Visual Studio, Dev-C++）打开。
3. 编译并运行，在控制台根据菜单提示输入数字进行操作。
